# 使用说明与操作清单

## 一、安装

1. 安装插件：

   ```
   /plugin marketplace add chinbor/auto-router
   /plugin install auto-router@auto-router
   ```

2. （可选）安装外派用的工具，装一个或两个都行；都没装也能用模型切换和省额度，只是没有外派：
   - pi：配好各家的 key，`pi --list-models` 里能看到模型就行；
   - opencode：`npm i -g @opencode/cli`，免费模型不用 key，`opencode models` 里能看到 `opencode/` 开头的模型就行。
3. （可选）看图工具 `scripts/img_check.py` 需要 Python；处理视频截帧需要 ffmpeg。
4. 重开一个会话。第一次运行会生成 `~/.claude/auto-router.json`，换模型和省额度这时就已经在工作了。几秒后插件在后台检测本机有没有 pi 和 opencode：都没装就不提供外派；装了的只开着检测到的提供商，并按档位排好角色。

## 二、首次配置（5 分钟）

第一次打开 `/auto-router` 时，Claude 页顶部有“🚀 快速开始”卡片，四步就够：① 去外派页选模型、② 选数据目录（日志和报告放哪，想躲开清理 `~/.claude` 的工具就放到别的盘）、③ 对照实验（推荐先只测模型切换 `route`，一个实验攒样本最快）、④ 复制每周报告的提示词。点“设好了，收起”后卡片收起，在“更多设置 → 📁 数据与报告”里可以重新显示。其余设置都有默认值，不用动。四步都可以跳过：不配也能用，只是没有外派、日志放在默认目录、不做对照实验。

实验开着时，会改变配置版本的设置（切换细节、省额度）旁边会提示“改这里会从头攒样本”：改了以后对照实验只比新版本的会话。

下面是外派模型的细调：

| 步骤 | 操作 |
|---|---|
| 1 | 运行 `/auto-router`，进入「外派模型」页。页面分两组：① pi 通道、② opencode 通道（OpenCode 免费模型，加上你在 opencode 里配的其他家，记成 `oc:提供商/模型`） |
| 2 | 每家选"免费 / 订阅 / 按量付费 / 不用"。没启用的几家收成一行“还有 N 家没启用”，点“展开，选一家启用” |
| 3 | 启用的每家下面列出全部模型，给要用的标"强 / 中 / 轻"，③ 派活顺序立即重排。模型超过 12 个时没选档位的先收起 |
| 3a | （用 opencode 时）在 opencode 一组的下拉里决定标黄的免费模型（提供方会保存内容）在哪用：不用（默认）/ 只在当前目录用 / 所有目录都用 |
| 4 | 切到「Claude 模型」页，确认每类问题用哪个模型（默认值一般就行） |
| 5 | （可选）"更多设置"里打开对照实验，选 `both` |

也可以直接跟 Claude 说，比如"code 角色改成 sol 优先""把 2027-01-01 到 01-03 加进 deepseek 的节假日"。Claude 会用 `router_config` 工具修改，保存前会校验。

## 三、每项能力怎么触发

### 模型切换（自动）

| 想要 | 怎么做 |
|---|---|
| 自动切换 | 什么都不用做：会话开头、隔了一小时以上、上下文刚压缩时自动分类定模型（状态栏“❄”），中间沿用，遇到难题、评审或你纠正时当场升档；状态栏显示本轮模型和理由 |
| 临时固定某个模型 | `/auto-router` → Claude 页 → 切换方式选"固定 opus"等 |
| 完全不切换 | 切换方式选"不切换" |
| 某类问题指定具体 Claude 版本 | Claude 页点“⟳ 刷新”，每类问题的下拉里除了 haiku / sonnet / opus / fable（“最新”，跟着 Claude Code 走新版），还有 pi 清单里列出的具体版本（“固定”，如 Opus 4.8）；清单来自 `pi --list-models` 里 anthropic 的模型 |
| 当前模型不够用 | 直接说"不对""重做"，本轮升一档 |
| 分类好像不工作 | 跟 Claude 说"用 router_config 的 probe 检查一下分类器" |

### 外派（pi / opencode）

| 想要 | 怎么做 |
|---|---|
| 让 Claude 自己决定外派 | 默认开着：分类判断适合外派时，会给 Claude 附一句建议 |
| 明确要外派 | 跟 Claude 说"把这个交给 bulk 角色做" |
| 指定用免费模型 | 跟 Claude 说"派给 opencode/glm-5.3-flash-free"；结果开头标 `[opencode …]` |
| 看走的哪条通道 | 结果开头、状态行（`🚀 opencode · 文本 · …`）、任务页都标着 pi 或 opencode |
| 手动派任务 | `/auto-router run [角色] <任务>`，后台运行，完成后提示 |
| 看任务 | `/auto-router jobs` |
| 取后台任务结果 | Claude 调 `pi_result`，或在任务页看 |
| 官方出了新模型、或自己在 pi / opencode 里加了模型 | 面板「外派模型」页点“刷新模型列表”，重新读 `pi --list-models` 和 `opencode models`；页面按通道分两组：① pi（每家一行选付费方式，下面列出它的全部模型选档位）、② opencode（免费模型）。新增的标“新”，选个档位就自动加入派活；下架的会写出来 |
| 看模型此刻能不能用 | 面板「外派模型」页点“测一下能不能用”，每个模型发一句“回复 OK”，标 ✓ 或 ✗ 原因；不记任务 |
| 某家被熔断了 | 面板「外派模型」页，那家提供商上点"恢复"；opencode 免费模型额度用完时只停那一个，派活顺序里写着几点恢复 |

可写角色要求工作目录是干净的 git 仓库。外派的模型改完不会自动提交，由 Claude 用 `git diff` 审阅后再决定保留还是撤销。只读角色在两条通道上都真的不能写：pi 禁掉 edit / write / bash，opencode 换成插件注入的只读代理（不是 `plan`，`plan` 还能跑 bash）。

### 省额度（自动）

| 场景 | 会发生什么 | 你要做的 |
|---|---|---|
| Claude 要读大文件、大图、整页网页 | 第一次被拦下，并提示更省的读法（offset/limit、预览图、按目标摘取） | 一般什么都不用做；确实需要全文时让 Claude 原样再请求一次，会放行 |
| 上下文超过 20 万 / 40 万 | 用户消息旁附一句提醒 | 换话题就用 `handoff` 技能交接后开新会话；继续同一件事就 `/compact` |
| 长对话歇了一小时以上再回来 | 弹一条提示：缓存已过期，这一轮要整段重写，约多少钱 | 做别的事就开新会话；还做这件事，等这轮答完 `/compact` |
| 7 天额度用过 70% | 提醒大量阅读优先派给 pi longctx | 无 |
| 要翻大量材料 | Claude 按规则选择自己读、scout 或 pi longctx | 想指定时直接说"用 scout 查"或"派给 pi longctx" |
| 要批量机械执行 | Claude 先读 `delegate` 技能，写好清单再交给 executor 或 pi | 无 |

开关在 Claude 页"更多设置"：省额度总开关、拦截开关、大量阅读交给谁。

### 对照实验

| 想要 | 怎么做 |
|---|---|
| 开始实验 | 更多设置 → 对照实验 → `route` / `saver` / `both` |
| 看本会话在哪组 | 面板"对照实验"下方；或 `/auto-router eval` 第一行 |
| 看报告 | `/auto-router eval [天数]`，默认 14 天 |
| 看摘要 | `/auto-router stats` |
| 原始数据 | `/auto-router path` 显示日志目录；`<dataDir>/report/latest.md` 是每小时更新的报告文件，周报照 [weekly-report.md](weekly-report.md) 写 |

结论规则：每组至少 15 个会话（不到 3 轮的不算），按会话花费的几何平均比较，差值超过两倍标准误才下结论。设计细节见 [experiment.md](experiment.md)。

## 四、命令速查

| 命令 | 作用 |
|---|---|
| `/auto-router` | 打开设置面板 |
| `/auto-router pi` / `stats` / `jobs` | 直接打开对应页 |
| `/auto-router eval [天数]` | 对照实验报告 |
| `/auto-router run [角色] <任务>` | 手动派外派任务（按角色的链走 pi 或 opencode） |
| `/auto-router export [文件]` | 导出配置给别人 |
| `/auto-router import <文件>` | 导入配置，旧配置备份成 `.bak` |
| `/auto-router path` | 显示配置文件、日志和报告文件的位置，并立即更新一次报告文件 |
| `/auto-router weekly [周报目录]` | 生成每周报告的提示词（已填好本机路径）和各平台怎么设定时任务，见 [weekly-report.md](weekly-report.md#怎么设定时任务) |
| `/auto-router doctor` | 自检：配置能否读、数据目录能否写、最近有没有记日志、分类是否常失败、报告是否过期、外派模型清单和暂停情况、实验状态，每项标 ✓ / ⚠ / ✗ |

| 工具（Claude 调用） | 作用 |
|---|---|
| `pi_dispatch` | 派任务给 pi 或 opencode（`opencode/` 开头的模型走 opencode；名字沿用旧的） |
| `pi_result` | 取后台任务结果 |
| `router_config` | `get` / `set` / `reset` 配置，`probe` 自检分类器 |

## 五、排查

先跑 `/auto-router doctor`，大多数问题它会直接指出来。

| 现象 | 原因和办法 |
|---|---|
| 日志里分类全是"超时"或"分类出错" | 多半是插件自己的模型请求被 429 限流（额度用到八成以上时常见）。这几轮会保持当前模型。想让它改用主模型 fork 来分，在「Claude 模型」页 → 更多设置打开“分类失败时 fork”（长对话里很贵）；用 `probe` 确认哪条路能通 |
| 第一条消息没切换 | 正常现象：还没有可 fork 的请求 |
| 日志里有"跳过（换不了模型）" | 已经在 Opus 且上下文长到不降档，分类没有意义，省掉了 fork |
| 外派任务一直在排队 | 能接这个角色的模型都在高峰或被暂停；面板「外派模型」页看状态，或把节假日加进配置 |
| 结果里写"跳过（已下架）" | 这个免费模型 opencode 已经不提供了；面板里它被划掉，派活时自动换下一个。可以给它选"不用"，或在 ③ 下面点"恢复按档位排"（只在顺序手调过时出现） |
| 结果里写"跳过（…不在 opencode.allowDirs 里）" | 这个免费模型官方说明会记录使用，默认不在任何目录用。确实不在意时在 opencode 一组的下拉里选"只在当前目录用"或"所有目录都用" |
| 升级后配置变了 | 0.2 的配置会自动加上 opencode；还是旧默认角色的会按新档位重排，原文件存成 `auto-router.json.bak` |
| 可写任务被拒 | 工作目录不是 git 仓库，或有未提交的改动；先提交或 stash |
| 手改配置后弹"校验不通过" | 按提示修改，或让 Claude 用 `router_config reset` 恢复默认（旧配置备份成 `.bak`） |
| 拦截误伤 | 原样再请求一次就会放行；频繁误伤可以关掉拦截开关，并提 issue |
